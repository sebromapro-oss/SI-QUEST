Codeur absolu — Décodage Gray sur quatre bits

Situation professionnelle : Un automaticien décode les quatre pistes d'un codeur absolu didactique.

Objectifs, prérequis et réactivation

Univers : SI-09. Sous-savoir : Décodage XOR cumulatif d'un mot Gray réfléchi sur quatre bits

Objectif : Retrouver la position binaire de 0 à 15 à partir du mot Gray.

Prérequis : Binaire, XOR et bits de poids fort/faible.

Critères de réussite : loi, unités, calcul, contrôle physique et décision.

Questions flash

  1. Combien vaut 1 XOR 1 ?
  2. Quel bit binaire recopie le bit Gray de poids fort ?
  3. Pourquoi le code Gray change-t-il d'un bit par position voisine ?

Modèle scientifique et hypothèses

b₃=g₃ ; b₂=b₃⊕g₂ ; b₁=b₂⊕g₁ ; b₀=b₁⊕g₀

Mot Gray réfléchi entier sur quatre bits de 0 à 15 ; transmission idéale ; pas de multi-tours.

Schéma 2D de principe, aucune 3D ni animation temporelle physique. Schéma et graphe verrouillés avant réussite ou corrigé.

Graphe verrouillé avant le calcul.

Calcul de l'élève

Paramètre nominal : 6 comptes ; réponse en comptes ; tolérance absolue ±0 comptes.

À toi de calculer.

Investigation et décision professionnelle

Plage fictive 0 à 15 ; contrôler la documentation du codeur réel.

Erreur fréquente : Le mot Gray ne s'interprète pas directement comme un binaire.

Calcul préalable nécessaire.
