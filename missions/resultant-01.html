Résultante orthogonale

Situation de contrôle technique : Deux forces perpendiculaires : Fₓ = 300 N constant et Fᵧ = 400 N au point nominal. Détermine le résultat du modèle avant d'étudier l'influence du paramètre.

Objectifs, prérequis et réactivation

Univers : SI-03 ; sous-savoir : somme vectorielle de deux forces coplanaires orthogonales.

Situation métier : un technicien étudie les efforts au point d'attache d'un dispositif de manutention fictif. Les deux composantes positives sont mesurées selon x vers la droite et y vers le haut.

Objectif : calculer le module de la résultante R sans confondre module et composantes signées.

Prérequis : vecteurs orthogonaux, théorème de Pythagore, newton (N), repère cartésien.

Critères de réussite : identifier les axes, écrire Rₓ=Fₓ et Rᵧ=Fᵧ, calculer R en N, contrôler R≥|Fₓ| et R≥|Fᵧ|, interpréter l'effort.

Questions flash

  1. Dans quel repère les deux composantes sont-elles exprimées ?
  2. Pourquoi ne faut-il pas additionner directement 300 N et 400 N pour obtenir le module ?
  3. Que vaut le module si Fᵧ=0 N ?

Repères et hypothèses : Fₓ=+300 N ; Fᵧ variable de 0 à +800 N ; les forces sont concourantes et perpendiculaires. Le module R=√(Fₓ²+Fᵧ²) est toujours positif ; aucun équilibre statique n'est déduit de ce seul calcul.

Modèle physique

R = √(Fₓ² + Fᵧ²)

Hypothèses et domaine : Forces coplanaires orthogonales appliquées au même point : Fₓ = 300 N constant, Fᵧ variable de 0 à 800 N ; valeur initiale Fᵧ = 400 N. Ce calcul ne constitue pas à lui seul une autorisation d'intervention.

Courbe du modèle disponible.

Calcul de l'élève

Calcule la valeur recherchée (N). Tolérance : ±0,5 N ; résultat présenté à 1 décimale.

À toi de calculer.

Investigation

Calcul préalable nécessaire.
