# SI QUEST — reconstruction depuis les fondations

**Cycle 00 — socle initial.** Dépôt privé, sans publication GitHub Pages. Ancienne version (jusqu'au cycle 28) conservée sur `archive/pre-reconstruction-cycle28-20261025` pour référence, sans réutilisation automatique de fonctionnalités non validées.

## Objectif
Construire un jeu de sciences industrielles structuré en 17 univers scientifiques, avec une cible de 249 sous-savoirs et 996 niveaux réellement distincts. Ces chiffres sont des **objectifs**, pas du contenu disponible.

## Méthode de reconstruction
1. Cycle 00 : socle accessible, navigation, registre d'exigences et tests de base.
2. Cycle 01 : premier scénario professionnel, modèle physique indépendant, calculs vérifiables, essai interactif, rétroaction, sauvegarde et preuves.
3. Cycles suivants : ajouter uniquement des niveaux autonomes, puis contrôler les régressions avant validation.

**Aucun niveau n'est déclaré jouable dans ce cycle 00.** Pas de simulation décorative ni de badges fictifs.

## Vérifications
`node --test tests/*.test.cjs`

Aucune recette sur appareils physiques, lecteur d'écran ou PWA n'est revendiquée. Accueil et carte seront stabilisés avant la production des missions et ne seront pas refondus à chaque cycle.
