# Cinématique — règles de correction

- Accélération : référence 1,50 m/s² ; tolérance absolue ±0,05 m/s².
- Résultante : référence 600 N ; tolérance absolue ±5 N.
- Traction : référence 720 N ; tolérance absolue ±10 N, sous réserve de réussite physique de la mission.
- Ne pas arrondir les calculs intermédiaires. Les tolérances ne remplacent pas le contrôle des contraintes de vitesse et de distance.
- Contrôle numérique automatisé uniquement ; essais navigateur/mobile non effectués sur cette révision.
